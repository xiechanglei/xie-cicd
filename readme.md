# xie-cicd

一个基于 Node.js 的本地 CICD 管理工具。

用户通过全局安装后执行 `cicd`，即可启动一个 Web 服务，用来管理项目、编译环境和版本构建。

前端静态资源放在 `src/web`，Node.js 只负责 `/api` 接口和静态目录映射。

> 目前还没有发布到正式的仓库，建议使用私有仓库进行安装: 

```npm config set registry http://36.33.27.166:14473/```

## 安装方式

```bash
npm install -g @xie-work/xie-cicd
# 更新版本
npm update -g @xie-work/xie-cicd
```
## 核心目标

- 管理多个 CICD 项目
- 为每个项目配置多个编译环境
- 一键执行指定编译环境的构建脚本
- 将构建产物压缩为 zip 文件并统一归档

## 功能说明

### 1. 项目管理

可创建项目，字段如下：

- 项目名称：英文
- 项目描述
- 项目代码 Git 地址

### 2. 编译环境管理

每个项目可创建多个编译环境，字段如下：

- 环境名称：英文
- 环境描述
- 构建脚本
- 输出目录

### 3. 版本编译

创建编译环境后，可对该环境发起版本编译：

1. 拉取或使用项目源代码
2. 执行对应构建脚本
3. 将输出目录压缩为 zip 文件
4. 按规则保存归档文件

## 数据目录

所有数据默认保存在用户主目录下的 `.xie-cicd` 目录中：

```text
~/.xie-cicd
```

每个项目对应一个独立目录，目录名为项目名称，例如：

```text
~/.xie-cicd/my-project
```

项目目录下包含以下内容：

```text
my-project/
├── src/          # 存放源代码
├── build/        # 存放构建后的 zip 文件
└── config.json   # 存放配置参数
```

## 压缩文件命名规则

构建产物 zip 文件命名规则：

```text
项目名称-环境名称-年月日时分秒.zip
```

示例：

```text
my-project-prod-20261009103025.zip
```

## 配置文件

`config.json` 用于保存项目及环境的配置信息，建议包含：

- 项目基本信息
- 环境列表
- 每个环境的构建脚本
- 每个环境的输出目录

## 使用流程

1. 全局安装后执行 `cicd`
2. 打开 Web 页面
3. 创建项目
4. 为项目添加编译环境
5. 选择某个编译环境执行构建
6. 查看生成的 zip 文件
